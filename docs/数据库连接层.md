# 数据库连接层设计

## 目标

- 业务代码不依赖具体数据库驱动。
- PGlite 作为默认嵌入式库，开箱即用；PostgreSQL 作为同协议生产适配器。
- 模块可独立启停、替换，不互相 import。
- 所有查询有边界：只读、限行、审计。

## 分层

```text
React 页面
  └─ src/api/client.ts            统一 fetch 客户端
       └─ /api/*                  HTTP 模块路由（server/modules/*）
            └─ Repository        每个领域独立 SQL（server/modules/*/repository.js）
                 └─ DatabaseAdapter  统一 query / transaction / health 契约
                      ├─ PGliteAdapter
                      └─ PostgresAdapter
```

页面不 import 数据库驱动；Repository 不 import HTTP；Adapter 不 import 业务模块。

## 目录

```text
server/
  config.js                 环境变量
  index.js                  API + 静态资源 + 生命周期
  db/
    index.js                驱动注册表
    migrate.js              迁移执行器
    seed.js                 演示数据（幂等）
    adapters/
      pglite.js             唯一 import @electric-sql/pglite 的位置
      postgres.js           唯一 import pg 的位置
    migrations/

  modules/
    index.js                模块清单 + MODULES 切片
    institutions/           repository + route
    catalog/
    assets/
    quality/
    indicators/
    residents/
    channels/
    query/                  只读 SQL + 审计
  http/
    router.js
    app.js
```

## 切换数据库

```bash
# 默认 PGlite
npm start

# PostgreSQL
DB_DRIVER=postgres DATABASE_URL=postgres://user:pass@host:5432/health npm start
```

新增达梦/金仓/MySQL：

1. 在 `server/db/adapters/` 新增 Adapter，实现 `connect / query / exec / transaction / health / close`。
2. 在 `server/db/index.js` 注册 `driver`。
3. 不改 `server/modules/**` 与前端。

## 模块切片

```bash
# 只挂载机构、目录、资产
MODULES=institutions,catalog,assets npm start
```

`server/modules/index.js` 是唯一模块清单；每个模块自己注册路由，不依赖其他模块。

## 安全边界

- 仅允许 `SELECT` / `WITH`，禁止多语句和写关键字。
- 结果强制 `LIMIT`（`QUERY_MAX_ROWS`，默认 200）。
- 查询与失败写入 `audit_logs`。
- 预览表名只接受 `^[a-z_][a-z0-9_]*$` 的 schema/table。
- PGlite 数据目录 `.data/pglite`，不提交仓库。

## 采集入仓

`POST /api/warehouse/ingest` 接收 `{ sources: [{alias, table}], targetPrefix }`，在事务内对每个源执行：

```sql
DROP TABLE IF EXISTS warehouse.<prefix>_<alias>;
CREATE TABLE warehouse.<prefix>_<alias> AS
SELECT *, now() AS ingested_at FROM <source_table>;
```

执行结果写入 `warehouse.ingest_jobs`，返回每张表行数与耗时。源表可为 `ods_his.patient`、`source_lis.lab_report`、`source_emr.visit`；表名和别名均做正则校验。
